# Portofolio (React + Vite)

## Jalankan lokal
    npm install
    npm run dev

## Ubah konten
Edit `src/data.js` (nama, proyek, skill, kontak) dan `<title>` di `index.html`.

## Deploy ke Vercel
1. Push folder ini ke GitHub.
2. Di vercel.com klik **Add New → Project**, pilih repo.
3. Vercel otomatis mengenali Vite (Build: `npm run build`, Output: `dist`). Klik **Deploy**.
